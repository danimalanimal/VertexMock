VERTEX Free Throw %

Set size

Shots per athlete. 25 is the standard combine set; 100 for serious shooting workouts.

How to run

  1. 1
    Set-up

    Standard NBA/NCAA free throw line, 15 ft (4.57m) from the backboard. Rebounder + passer for fast turnaround.

  2. 2
    Brief athlete

    Routine each shot (dribble, breath, set). No coaching during the set. Coach stands beside, phone in hand.

  3. 3
    Record

    Tap the big green MAKE button on each made basket, MISS on each miss. Live tally + streak shown above the buttons. Tap UNDO to fix mis-taps.

  4. 4
    Next athlete

    When the set completes (auto-detected) you'll see a Next Athlete prompt. Or skip remaining shots to advance.

  5. 5
    Scoring

    Final % + longest streak per athlete. Save to fitness stats.

Tips
  • 1 minute rest between athletes
  • Don't let athletes see live count — pressure changes results
  • Same ball, same hoop, ideally same time of day for comparisons

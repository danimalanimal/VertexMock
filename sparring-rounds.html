How to use

  1. 1
    Configure

    Pick round length, rest length, and number of rounds. Defaults match standard amateur boxing (3 × 3min / 1min rest).

  2. 2
    Place phone

    Stand the phone at ringside where both corners can hear it. Set volume to max — audio cues are critical.

  3. 3
    Tap START

    The HUD flips to WORK. Bell at start + end of each round. 10-second warning beep at the end of every phase.

  4. 4
    Log events

    Tap the score buttons during the round to log knockdowns, standing-8 counts, or warnings. These show up in the results breakdown.

  5. 5
    Auto-cycle

    Phase transitions are automatic. Pause anytime if you need a break.

Safety
  • Always gear-check before sparring (mouthguard, headgear, gloves, cup)
  • Stop on dizziness, headache, or hard head contact — defer to a coach
  • Match level + size — never pair a beginner with an experienced fighter
